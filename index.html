## 首先，raylib和raygui是干什么的？
raylib是一个轻量级的，十分易用的制作2D或3D游戏或视频的库，raygui则是raylib的补充，也就是为游戏创作GUI界面的。既然是GUI，代码量肯定不小。但是我要告诉你，raygui的代码量非常小，小到什么程度那？
```cpp
InitWindow(参数1，参数2，参数3)；
```
这一行代码，就可以创建一个窗口。但是不代表生成的.exe可以运行。
反观隔壁WindowsAPI,就写一个窗口，就要:
```cpp
#include <windows.h>

/* 在这里处理所有的窗口消息（包括输入） */
LRESULT CALLBACK WndProc(HWND hwnd, UINT Message, WPARAM wParam, LPARAM lParam) {
switch(Message) {

/* 销毁（关闭）窗口时，让主线程退出 */
case WM_DESTROY: {
PostQuitMessage(0);
break;
}

/* 使用默认的输出过程来处理所有其他消息 */
default:
return DefWindowProc(hwnd, Message, wParam, lParam);
}
return 0;
}

/* Win32 GUI程序的“main”函数：程序从这里开始执行 */
int WINAPI WinMain(HINSTANCE hInstance, HINSTANCE hPrevInstance, LPSTR lpCmdLine, int nCmdShow) {
WNDCLASSEX wc; /* 用于设置窗口的属性 */
HWND hwnd; /* 我们的窗口句柄（H代表handle（句柄），WND代表windows（窗口）） */
MSG msg; /* 用于临时保存收到的消息 */

/* 先将整个结构全部置零，然后再设置需要的字段 */
memset(&wc,0,sizeof(wc));
wc.cbSize = sizeof(WNDCLASSEX);
wc.lpfnWndProc = WndProc; /* This is where we will send messages to */
wc.hInstance = hInstance;
wc.hCursor = LoadCursor(NULL, IDC_ARROW);

/* COLOR_WINDOWS+1为白色。Ctrl+鼠标左键点击COLOR_WINDOW可以查看它的定义 */
wc.hbrBackground = (HBRUSH)(COLOR_WINDOW+1);
wc.lpszClassName = "WindowClass";
wc.hIcon = LoadIcon(NULL, IDI_APPLICATION); /* 加载标准图标 */
wc.hIconSm = LoadIcon(NULL, IDI_APPLICATION); /* 加载标准图标 */

if(!RegisterClassEx(&wc)) {
MessageBox(NULL, "Window Registration Failed!","Error!",MB_ICONEXCLAMATION|MB_OK);
return 0;
}

hwnd = CreateWindowEx(WS_EX_CLIENTEDGE,"WindowClass","Caption",WS_VISIBLE|WS_OVERLAPPEDWINDOW,
CW_USEDEFAULT, /* x */
CW_USEDEFAULT, /* y */
640, /* 窗口宽度 */
480, /* 窗口高度 */
NULL,NULL,hInstance,NULL);

if(hwnd == NULL) {
MessageBox(NULL, "Window Creation Failed!","Error!",MB_ICONEXCLAMATION|MB_OK);
return 0;
}

/*
这里是我们程序的核心部分。所有的消息（包括输入）都通过这个循环
调用WndProc函数处理。注意GetMessage会程序暂时休眠，直到它收到
任意消息为止。所以这个循环不会导致过高的占用CPU。
*/
while(GetMessage(&msg, NULL, 0, 0) > 0) { /* 如果没有发生错误，且收到了任意消息... */
TranslateMessage(&msg); /* 将消息中的键盘码转换为对应的字符 */
DispatchMessage(&msg); /* 调用WndProc函数处理消息 */
}
return msg.wParam;
}
```
你可能会问我，为什么注释写得这么奇怪？ 因为我其实也不会Win32API! 这段代码实际上是IDE自带的。

当然了，Win32API不在我们讨论的范畴内，我们还是回归正题。

写一个最简单的raygui程序的示例：

```cpp
#include <raylib.h>
#define RAYGUI_IMPLEMENTATION
#include <raygui.h>
int main(){
InitWindow(1500,750,"raygui示例");
while(!WindowShouldClose()){
BeginDrawing();
ClearBackground(WHITE);
EndDrawing();
}
return 0;
}
```

## 基础
我们先对raygui中的基础常用函数进行介绍，掌握GUI的开发，是一切的基础。

#### 窗口创建
```cpp
#include <raylib.h>//头文件，注意是c语言的.h
//第3行是进行预编译，具体原理无需深究，正常写代码仅需知道使用raygui.h必须加就可以
#define RAYGUI_IMPLEMENTATION
#include <raygui.h>//注意！raygui.h是基于raylib的所以必须先包含raylib.h在包含raygui.h
int main(){

InitWindow(1500,750,"raygui示例");//这个函数创建了一个窗口，第一个参数为长，第二个参数为高，第三个参数为窗口标题

while(!WindowShouldClose()){
//主消息循环，所有gui都是从这里实现的
BeginDrawing();
ClearBackground(WHITE);//将窗口背景设为白色
EndDrawing();
//BeginDrawing()和EndDrawing()两个函数可以理解为BeginDrawing()是每一帧绘制的开始，而EndDrawing()是这一帧的结束
}

return 0;
}
```
这个代码已经注释好了，接下来我会逐一讲解用到的函数。

1.WindowShouldClose()函数

```cpp
WindowShouldClose()
```
这个函数就是用于侦测窗口是否被人为关闭，原型如下：
```cpp
bool WindowShouldClose(void);
```
括号内不传入任何参数，只是作为主消息循环的结束条件。

2.BeginDrawing()函数
```cpp
BeginDrawing()
```
这个函数就是用于开始某一帧的绘制，原型如下:
```cpp
void BeginDrawing(void)
```
这个函数必须和EndDrawing()成对使用，也就是一帧要有始有终。

3.ClearBackground()函数
```cpp
ClearBackground(参数1)
```
这个函数就是将窗口的背景颜色设为括号内参数的颜色。原型如下：
```cpp
void ClearBackground(Color color)
```
Color是raylib中的自定义类型，也就是颜色。

raylib头文件中对于不同颜色的定义如下：

4.EndDrawing()函数

这个函数的用法上面已经介绍了，就是和BeginDrawing()配对使用。

小结：上面介绍的几个函数，其实都是在raylib.h中的，但是这也是GUI的基础，所以笔者也将他们归于raygui了。

#### 基础控件及文字输出
基础控件笔者在这里只想介绍一个控件，也是最常用的控件。读完这节，相信你也可以利用raygui创建简单的GUI交互界面了。

废话少说，先上一段代码:
```cpp
#include <raylib.h>
#define RAYGUI_IMPLEMENTATION
#include <raygui.h>

using namespace std;

int main(){

InitWindow(1500,1300,"RAYGUI示例2");
SetTraceLogLevel(LOG_WARNING);

//第13行就相当于一个字典
const char *guitexts="1号按钮我的第一个窗口";
//将字典中的字符转化成Unicode码点
int codepointscount;
int *codepoints=LoadCodepoints(guitexts,&codepointscount);
//读取字体
Font font=LoadFontEx("C:\\Windows\\Fonts\\simhei.ttf",64,codepoints,codepointscount);
//释放码点表
UnloadCodepoints(codepoints);

//设置控件（注意是控件！！！）的字体和大小
GuiSetFont(font);//设置字体
GuiSetStyle(DEFAULT,TEXT_SIZE,20);//设置字的大小

while(!WindowShouldClose()){
//主消息循环
BeginDrawing();
ClearBackground(WHITE);
GuiButton((Rectangle){120,150,200,60},"1号按钮");
DrawTextEx(font,"我的第一个窗口",Vector2{50,50},50,1,BLACK);
EndDrawing();
}
//释放字体
UnloadFont(font);
return 0;
}
```

你可能会问我，为什么主消息循环每一行不写注释了？

而我会告诉你，这里的几个函数（除了已经讲过的）都是在注释中没法讲明白的。

你还可能会问我，不是说只讲一个控件和输出文字吗？为什么在主消息循环前有这么一大堆？

实际上，如果在GUI中使用非ASCII字符，你需要先将你需要使用的字符转化为Unicode码点。我再回答一个问题：为什么不使用DrawText()函数？因为这个函数比较鸡肋，无法自定义文字的颜色和字体，所以笔者在这里不做介绍。

1.SetTraceLogLevel()函数

这个函数的原理初学者不必深究，只需要知道使用raygui控件就需要在代码的头部（主函数内）加上下面这一行:
```cpp
SetTraceLogLevel(LOG_WARNING);
```
如果不加会导致链接错误。

2.LoadCodepoints()函数
```cpp
LoadCodepoints(参数1,参数2)
```
原型为:
```cpp
int *LoadCodepoints(const char *text, int *count)
```
返回int *类型，所以我们要用一个指针来存储该函数的返回值。

参数1传入的是一个const char *类型，可以理解为字符数组。

参数2传入的是int *类型，所以在传入的时候笔者加了&取地址符。

3.LoadFontEx()函数


```cpp
LoadFontEx(参数1,参数2,参数3,参数4)
```
该函数实现了将字体载入的功能,该函数的原型为：
```cpp
Font LoadFontEx(const char *fileName, int fontSize, int *codepoints, int codepointCount)
```
参数1传入的是字体文件的路径（必须是绝对路径！！！）。

参数2传入的是字体文件的大小。

参数3传入的是码点表的地址（指针类型）。

参数4传入的是字典字符串的长度。

4.UnloadCodepoints()函数
```cpp
UnloadCodepoints(参数1)
```
该函数实现了载入字体之后将码点表释放的功能，其原型为：
```cpp
void UnloadCodepoints(int *codepoints)
```
该函数无返回值，传入一个指针类型(int *)，只是实现功能。

参数1传入的是一个指针类型，没什么好说的。

5.GuiSetFont()函数
```cpp
GuisetFont(参数1)
```
该函数实现的是设置GUI控件的字体，注意在窗口上输出文字或图片（使用上面介绍的DrawTextEx()函数）使用的字体是该函数的第一个参数。当然，如果使用不同的字体，也需要重新写字典并将字典转化成Unicode码点并释放码点表。

该函数的原型如下：
```cpp
void GuiSetFont(Font font)
```
提示：Font是raylib中的自定义类型！！！

6.GuiSetStyle()函数
```cpp
GuiSetStyle(参数1，参数2，参数3)
```
该函数实现的是设置GUI的字号。该函数的原型如下：
```cpp
void GuiSetStyle(int control, int property, int value)
```
参数1和参数2传入的值一般不进行更改，一般使用上面那段完整代码传入的两个参数

参数3就是字号（是GUI控件的字号）

7.GuiButton()函数
```cpp
GuiButton(参数1，参数2)
```
该函数实现的是创建一个GUI控件——按钮的功能，该函数的原型如下：
```cpp
int GuiButton(Rectangle bounds, const char *text)
```
这个函数传入的参数1的格式如下:
```cpp
(Rectangle){xxx,xxx,xxx,xxx}
```
注：这里的xxx代表的是数字

可以得知，这里的花括号中有4个数字，用逗号隔开。

第一个数字表示你要创建的该控件在窗口中的x坐标，第二个数字表示y坐标，第三个表示按钮的长度，第四个表示按钮的高度。

参数2相对简单，传入一个字符串（必须是常量！！！）表示按钮上书写的文字。

在实际应用中，我们常常用变量来记录当前的状态，请看下面这段代码：
```cpp
#include <raylib.h>
#define RAYGUI_IMPLEMENTATION
#include <raygui.h>
#include <iostream>

using namespace std;

int main(){

InitWindow(1500,1300,"RAYGUI示例2");
SetTraceLogLevel(LOG_WARNING);

//第13行就相当于一个字典
const char *guitexts="1号按钮我您刚才点击了按钮的第一个窗口";
//将字典中的字符转化成Unicode码点
int codepointscount;
int *codepoints=LoadCodepoints(guitexts,&codepointscount);
//读取字体
Font font=LoadFontEx("C:\\Windows\\Fonts\\simhei.ttf",64,codepoints,codepointscount);
//释放码点表
UnloadCodepoints(codepoints);

//设置控件（注意是控件！！！）的字体和大小
GuiSetFont(font);//设置字体
GuiSetStyle(DEFAULT,TEXT_SIZE,20);//设置字的大小
cout<<codepointscount<<"\n";

int choose=0;
while(!WindowShouldClose()){
//主消息循环
BeginDrawing();
ClearBackground(WHITE);
if(choose==0&&GuiButton((Rectangle){1200,1000,200,60},"1号按钮")==true){
choose=1;
}
if(choose==1){
DrawTextEx(font,"您刚才点击了按钮",Vector2{50,50},50,1,BLACK);
}
else
DrawTextEx(font,"我的第一个窗口",Vector2{50,50},50,1,BLACK);
EndDrawing();
}
//释放字体
UnloadFont(font);
return 0;
}
```
这段代码实现了一个简单的GUI交互，在屏幕下方创建按钮1，点击按钮会改变屏幕上方的文字。

8.DrawTextEx()函数

上面两个代码都提到了DrawTextEx()函数，是因为不写这个函数人机交互的效果无法体现。在这里，笔者将系统地介绍这个函数。
```cpp
DrawTextEx(参数1，参数2，参数3，参数4，参数5，参数6)
```
这个函数实现的是在窗口的任意位置（当然窗口之外也行，不过就看不到了）输出任意字体、任意大小、任意颜色的字符串。这个函数的原型如下：
```cpp
void DrawTextEx(Font font, const char *text, Vector2 position, float fontSize, float spacing, Color tint)
```
打眼一看，似乎很复杂，但是我们可以把这个函数的6个参数分为4部分。

第一部分：参数1：传入你需要的字体（Font）类型。

第二部分：参数2：传入一个字符串（必须是常量），表示你要输出的文字。

第三部分：参数3、4、5这三个参数的意义很类似，第一个是传入的raylib中的二维向量（Vector2），我们后面会介绍到。花括号中第一个数表示你要从x坐标的什么位置开始输出，第二个数表示你要从y坐标的什么位置开始输出（x,y）是右上角的坐标。参数4是每个字的边长，参数5是字与字之间的间距。

小结：到这里我们的GUI基础部分告一段落了，利用上面的函数，已经可以创建简单的GUI了。下一部分，笔者将介绍raylib的基础（2D）。
